## Strong bullets template

- Designed a dependency-aware root-cause inference engine using temporal precedence, upstream centrality, anomaly severity, and deployment proximity scoring.
- Implemented deploy regression detection by comparing pre/post release error-rate and latency windows, automatically flagging release-induced incidents.
- Reduced alert noise by **X%** by clustering **Y** raw events into **Z** actionable incident groups in a simulated microservice environment.
- Achieved top-2 root cause identification accuracy of **X%** across **N** injected failure scenarios (timeout, DB contention, cascading error, failed deploy).

## Rules for final bullet selection
- Include one distributed-systems bullet
- Include one ML/analytics bullet
- Include one production engineering/SRE bullet
- Include one quantified impact bullet
